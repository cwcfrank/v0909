實作場 90 分鐘 ｜ 2026.09.09

90 分鐘，做出一個能公開上線的網站

下課時你會有 一個自己做的網站 ＋ 一個可以傳給任何人的公開網址。 照著圖做，每完成一步打個勾。

今天要走完的五步。每一步都有一張圖，照圖做就好。

今天最重要的一句話 新手叫 AI「做一個很棒的網站」。老手先叫 AI 反過來拷問自己。
STEP 0

開工前：認識三個地方

4–8 分

A Agent 對話框（你所有的話都對它說） B 你的 index.html　·　畫面細節可能跟你的不太一樣，找到這兩個東西就對了

  1. 打開 Antigravity（電腦上已經裝好了）→ 用 Google 帳號登入
  2. 模型選 Gemini 3.6 Flash（medium） ← 這一步很重要，看下面
  3. 開一個新資料夾當你的專案：名字用英文小寫、減號連接
今天你的 AI 對話次數是有限的 免費額度大約一天 20 次對話。這堂課的正常用量是 6～7 次（拷問 2 次、生成 1 次、修改 2 次、除錯 1～2 次）， 夠用——但不要拿它閒聊、不要一直重生成。用完就得等，今天就沒了。
模型選 Flash 而不是 Pro，也是為了省額度。
資料夾名字＝你網址的一部分 ✓ lunch-spin　　✕ 午餐轉盤　　✕ my project
用中文或有空格，第 7 步會壞。
STEP 1 ★

讓 AI 拷問你

8–16 分

它問你問題不是它笨，是它在避免做白工。

我想做一個 ______________ 的網頁小工具。

在你寫任何程式之前，請先拷問我，把我沒講清楚的地方問出來：
- 一次最多問我 5 個問題，一題一行、有編號
- 每一題都要附上「你建議的答案」和一句話理由
- 問完就停下來等我回答，不要自己假設、不要先寫程式
- 我回答後如果還有沒問清楚的，再問我第二輪（最多兩輪）

兩輪之後，請把結論整理成下面這樣給我，然後才開始寫程式：
【我要做的東西】一句話
【功能清單】三項，動詞開頭
【驗收方式】三個我可以自己動手確認的步驟
【我們決定不做的事】

技術限制（這些不用問我，直接照做）：
單一 index.html 檔案、不要用需要安裝的套件、不連資料庫、不需要登入功能。
它問到第三輪還在問 直接說：「不要再問了，照你的建議整理成規格然後開始寫。」
想先看一個做完的例子？ 有人選了「中午吃什麼的拉霸轉盤」——拷問時 AI 問他「紀錄要記『轉到什麼』還是『真的吃了什麼』」， 他自己完全沒想過這有差。看他的成品 ｜ 想看更誇張的：Minecraft 風格的版本
備用：它不問，直接開始寫程式

自己填完這三格貼給它：目的一句話 ／ 三個功能（動詞開頭）／ 三個驗收動作。

範例（喝水紀錄）：按一下加一杯 ／ 顯示今天幾杯 ／ 可以歸零； 驗收＝按 3 次變 3、關掉再開還在、歸零變 0。

STEP 2

確認規格，讓它開始寫

16–24 分
規格沒問題，請開始寫。寫完後告訴我怎麼一步一步測試上面的驗收方式。

等 1–2 分鐘，它會自己建立 index.html。

STEP 3

看成果

24 分

用瀏覽器打開就是真的網頁——按鈕、輸入、F5 全部都能測，跟上線後一模一樣。

打開是一片空白 跟 Agent 說：「網頁打開是空白的，請檢查 index.html 是否完整，並確認所有程式碼都寫在這一個檔案裡。」
改完之後怎麼再看一次 Agent 改完檔案後，回到已經開著的瀏覽器分頁按 F5 就會更新，不用重新雙擊。
STEP 4

改兩次，一次只改一件事

24–34 分

第一次改（挑一個）

加上刪除按鈕，按了那筆就消失
字改大一點，手機也看得清
完成的變灰色並移到最下面

第二次改（挑一個）

加上資料儲存，關掉再開資料還在
最上面顯示今天的日期
換成深色背景、亮色文字
STEP 5 ★

驗收儀式

34–44 分
當 AI 說「我已經完成並測試過了」 它沒有你的瀏覽器。它從來沒有點過你的網頁一下。

親手試一次：這就是等一下會發生在你身上的事

迷你網頁：喝水紀錄
今天喝了 0 杯

AI 說：「已完成並測試過，資料會自動儲存。」→ 按幾下「加一杯」，然後按 F5。

✓ 這樣說，它一次就中 我按了 3 次，數字有變 3。但按 F5 後變回 0。我要的是重新整理後還是 3。
✕ 這樣說，它只能猜「不會動，修一下」／「壞了」

公式：我做了什麼 → 我看到什麼 → 我期望看到什麼

STEP 6

把檔案放上 GitHub（你的第一個 commit）

44–58 分

全程在瀏覽器裡，不用打任何指令、不用設定任何密碼或 token。

找不到 index.html 在哪？ 回 Antigravity，在左邊的 index.html 上按右鍵 → 在檔案總管顯示， 檔案總管就會跳出來，直接把檔案拖進 GitHub 的上傳框。
兩個地雷 ① 一定要選 Public，選 Private 之後網址不會公開。
② 檔案一定要叫 index.html（全部小寫），叫別的名字第 7 步會 404。
STEP 7 ★

拿到你的公開網址

58–70 分

拿到網址 → 用手機打開確認活著 → 貼到班級展示牆

先組出你的網址（順便檢查資料夾名合不合法）

https://＿＿＿＿.github.io/＿＿＿＿/

打開是空白頁 等 2 分鐘再重新整理。還是空白就舉手——八成是 repo 選了 private，或首頁檔案不叫 index.html。
STEP 8

再改一件事，看見修改歷史

70–80 分
  1. 回 Antigravity，跟 Agent 說第 4 步的「第二次修改」那句
  2. 雙擊／F5 驗收（第 5 步的三個動作）
  3. 回 GitHub 你的專案 → Add file → Upload files → 把同一個 index.html 再拖一次
  4. 訊息寫「加上資料儲存」→ Commit changes（同名檔案會直接覆蓋，並產生第二個 commit）
  5. 點上方的 Commits → 你會看到兩筆記錄
  6. 等 1–2 分鐘，重新整理你的公開網址 → 網站自己更新了
加分題

讓你的網站跟別人不一樣

做完前面 8 步才進來
你可能已經用到了 Antigravity 常常自己就會引入 Three.js 或 GSAP（程式碼最上面出現 cdnjs.cloudflare.com 就是）。 看到不用緊張，那正是下面第 1、2 招。但要記得驗收——這些是從網路上抓的，校內網路擋掉就會壞掉。
三個前提，違反一個就不要加特效 ① 你的網站已經上線並驗收過（沒上線就先回 STEP 7）
② 一次只加一招（就是 STEP 4 那條規則，特效更容易一次改壞）
③ 每加一招就 commit 一次（壞了才回得去，就是 STEP 8 那件事）
01Three.js — 會動的 3D 背景 最有「哇」的效果

用 3D 函式庫在網頁最底層放一層緩慢飄動的粒子。這是最容易讓人記住你的網站的一招。

請用 CDN 引入 three.js（不要用 npm、不要拆成多個檔案），在我的網頁最底層加一個 3D 動態背景：緩慢飄動的粒子。

條件：
1. 只能新增背景層，現有的內容與功能完全不要動
2. 背景在內容下面，文字必須維持清楚可讀
3. 手機上自動降低粒子數量，不要讓手機卡住或發燙
4. 如果使用者系統設定了「減少動態效果」，就不要播動畫

改完後告訴我怎麼一步一步確認上面四點。

會踩的坑：手機會發燙、網頁變慢 → 粒子數先設小；校網若擋 CDN 會整片黑，記得按 F5 驗收。

02GSAP — 進場與滾動動畫 最容易看起來專業

讓標題和卡片依序滑進畫面，而不是全部一次跳出來。順序感是「做得很細」的第一印象。

請用 GSAP 的 CDN 版本，為現有元素加上進場動畫：標題與卡片依序淡入並輕微上移，每個間隔 0.08 秒。

條件：
1. 就算 JS 載入失敗，內容也必須看得到（不要讓元素卡在透明狀態）
2. 每個元素只播一次，不要每次滾動都重播
3. 尊重「減少動態效果」的系統設定
4. 不要改動任何原有的功能

改完後告訴我怎麼驗收這四點。

會踩的坑：動畫沒跑成功時，內容可能永遠是透明的 → 第 1 條就是在防這件事，一定要留。

03Design DNA — 先定設計基因，再改樣式 最省時間

先讓 AI 定一套顏色／字級／圓角／陰影／間距的規則，再要它「只准用這套規則」。這樣改十次也不會越改越亂。

在改任何樣式之前，先幫我定一套 design DNA，寫成 CSS 變數放在 :root：
主色、輔色、背景色、文字色各一；字級 4 級；圓角 2 種；陰影 2 種；間距用 4 的倍數。

然後把整個網頁改成只使用這些變數，不要留任何寫死的色碼或尺寸。

最後把這套 DNA 列出來給我看，並告訴我改了哪些地方。

會踩的坑：AI 會順手改掉你原本喜歡的顏色 → 它列出 DNA 時對照一次，不喜歡就叫它換掉那一個變數。

04Motion design — 動效要有意義 分辨新手與老手

新手加一堆會動的東西，老手只讓「使用者做了什麼」有回饋。少而準，比多而炫值錢。

請幫我做「互動回饋」而不是裝飾動畫：

1. 按鈕 hover 和按下時要有明顯但輕微的變化（120-180 毫秒）
2. 清單新增一筆時滑入，刪除時淡出
3. 每個動畫都要對應一個使用者動作，不要有無限循環的動畫
4. 所有動畫時間 ≤ 300 毫秒，進場用 ease-out、離場用 ease-in

改完告訴我每個動畫分別對應哪一個動作。

會踩的坑：動畫太多會讓人頭暈，展示時反而扣分 → 加完自己用一次，覺得煩就砍掉一半。

05視覺層次（Genjutsu）— 用光影騙出「很貴」的感覺 不用任何圖檔

純 CSS 做出景深：極淡雜訊、模糊光暈、毛玻璃、兩層陰影、滾動視差。沒有加任何圖片，但看起來像有設計師。

請只用 CSS 讓畫面更有層次感，不要使用任何圖片檔：

1. 全頁加一層極淡的雜訊質感
2. 主視覺後方放一顆模糊的漸層光暈
3. 卡片用毛玻璃效果（backdrop-filter）加兩層陰影
4. 滾動時背景和前景速度不同（視差），但手機上關掉視差

條件：文字的對比與可讀性不能變差。改完告訴我怎麼確認文字還是清楚的。

會踩的坑：光暈或雜訊太重會讓字變糊、毛玻璃在舊瀏覽器沒效果 → 加完把手機轉到最亮和最暗各看一次。

加完之後 回 STEP 5 做一次驗收（按一下、按 F5、拉窄），再回 STEP 8 commit 一次。 特效壞掉的機率比你想的高，但你已經會退回上一版了。
卡住了

三個急救指令

  1. 打不開／一片空白
    「網頁打開是空白的，請檢查 index.html 是否完整，並確認所有程式碼都寫在這一個檔案裡。」
  2. 改一次就整個壞掉
    「請退回上一個可以正常運作的版本，然後只做這一件事：______」
  3. 一直說完成但就是不對
    補上「我實際看到什麼」＋「我期望看到什麼」，並要它「先告訴我問題在哪，再改」。

卡超過 90 秒就舉手，那是我和助教的工作。
